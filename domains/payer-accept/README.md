# payer-accept — subjective evidence class

The honest pack for domains only a human can judge (design, research,
writing). Automated "verification" of subjective work is theater — this
pack does the two non-subjective jobs and declares `verdict_authority:
payer` on the record:

1. **resolves** the claimed artifact — URL refs fetched + `content_sha256`
   at claim time (payer reviews what was submitted, not a later edit)
2. **records** the actor — claimed, not verified

`verification.params` pass through to the verdict record — the payer
judges them, not the pack.
